# 時間複雜度 Time Complexity 基礎教學筆記

## 一、名詞解釋

時間複雜度（Time Complexity）是用來描述：

> 當資料量變大時，程式執行步驟數的成長速度。

它不是精準計算「程式跑幾秒」。

因為同一段程式在不同電腦上，實際秒數可能不同。

所以時間複雜度關心的是：

```text
資料量變大時，程式大概要多做多少事情？
```

---

# 二、Big-O 是什麼？

常看到：

```text
O(1)
O(log n)
O(n)
O(n²)
```

這裡的 `O` 不是數字 0。

它是：

```text
Big-O notation
大 O 表示法
```

## Big-O 的用途

Big-O 用來表示：

> 程式執行次數隨著資料量增加時的成長趨勢。

例如：

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

如果 `n = 10`，迴圈跑 10 次。

如果 `n = 100`，迴圈跑 100 次。

如果 `n = 1000`，迴圈跑 1000 次。

所以這段程式的執行次數會跟 `n` 成正比。

因此時間複雜度是：

```text
O(n)
```

## Big-O 的嚴謹補充：它主要表示「上界」

前面說 Big-O 是用來表示「成長速度」，這是國考與初學常用說法。

但更嚴謹地說：

```text
Big-O 表示成長的上界。
```

也就是說，如果一個演算法是：

```text
O(n)
```

可以理解成：

```text
當資料量變大時，執行步驟數最多大致跟 n 成正比成長。
```

國考在基礎題通常會把 Big-O 當作「時間複雜度的成長等級」來使用，因此寫「成長速度」通常可以接受。

---
# 三、n 是什麼？

`n` 通常代表：

```text
輸入資料的數量
```

或稱為：

```text
問題規模
```

## 常見例子

| 情境 | n 代表什麼 |
|---|---|
| 陣列搜尋 | 陣列長度 |
| 字串處理 | 字串長度 |
| 學生成績列表 | 學生人數 |
| 資料庫資料 | 資料筆數 |
| 樹狀結構 | 節點數量 |
| 圖形演算法 | 節點數或邊數 |

## 例子

```java
int[] arr = {10, 20, 30, 40, 50};
```

這個陣列有 5 個元素，所以：

```text
n = 5
```

如果陣列有 1000 個元素：

```text
n = 1000
```

所以 `n` 不是固定數字，而是代表資料量。

# 四、log 是什麼？

在時間複雜度中，`log n` 通常可以先理解成：

```text
資料量每次被縮小一部分
```

最常見的是：

```text
每次縮小一半
```

演算法裡的 `log n` 通常預設是：

```text
log₂ n
```

也就是：

> 2 要乘幾次，才會變成 n？

---

## log 範例

```text
log₂ 8 = 3
```

因為：

```text
2³ = 8
```

也就是：

```text
2 × 2 × 2 = 8
```

---

```text
log₂ 16 = 4
```

因為：

```text
2⁴ = 16
```

---

```text
log₂ 1024 = 10
```

因為：

```text
2¹⁰ = 1024
```

---

## log n 的白話意思

如果資料量是 1024 筆。

`O(n)` 可能要看 1024 次。

但 `O(log n)` 大約只需要看 10 次。

因為：

```text
1024 → 512 → 256 → 128 → 64 → 32 → 16 → 8 → 4 → 2 → 1
```

每次砍半，大約砍 10 次就結束。

所以：

```text
O(log n)
```

通常代表：

> 資料量變大時，執行次數增加得很慢。

## log 的嚴謹補充：Big-O 裡通常不在乎底數

前面用 `log₂ n` 是為了方便理解「每次砍半」的情況，例如二分搜尋。

但在 Big-O 表示法中：

```text
O(log₂ n)、O(log₁₀ n)、O(ln n) 通常都視為同一個等級。
```

原因是不同底數的 log 只差一個常數倍，而 Big-O 會忽略常數倍。

所以考試最後答案通常直接寫：

```text
O(log n)
```

不用特別寫成：

```text
O(log₂ n)
```

除非題目要求推導，或你想說明每次砍半時，才會用 `log₂ n` 來解釋。

---
# 五、O(...) 括弧裡面放什麼？

`O(...)` 的括弧裡面放的是：

```text
程式步驟數隨 n 成長的型態
```

常見有：

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
O(n³)
O(2ⁿ)
O(n!)
```

---

## 常見含義

| 表示法 | 名稱 | 白話意思 |
|---|---|---|
| O(1) | 常數時間 | 不管資料多大，執行次數固定 |
| O(log n) | 對數時間 | 每次把問題縮小，例如砍半 |
| O(n) | 線性時間 | 一筆一筆處理 |
| O(n log n) | 線性對數時間 | 常見於高效率排序 |
| O(n²) | 平方時間 | 雙層巢狀迴圈 |
| O(n³) | 立方時間 | 三層巢狀迴圈 |
| O(2ⁿ) | 指數時間 | 資料每增加一筆，可能成倍增加 |
| O(n!) | 階乘時間 | 常見於排列組合爆炸問題 |

---

# 六、時間複雜度的核心想法

時間複雜度不是在問：

```text
這段程式跑幾秒？
```

而是在問：

```text
當 n 越來越大，程式大概要做多少次基本操作？
```

基本操作可以是：

```text
比較一次
加法一次
指派一次
陣列取值一次
印出一次
```

國考或演算法分析通常不需要精準算每一次操作。

重點是看主要成長趨勢。

---

# 七、Big-O 會忽略什麼？

## 1. 忽略常數

例如：

```text
O(3n) → O(n)
O(100n) → O(n)
```

因為 Big-O 看的是成長趨勢，不看常數倍。

---

## 2. 忽略低次項

例如：

```text
O(n² + n) → O(n²)
```

原因是當 n 很大時，`n²` 成長遠比 `n` 快。

| n | n² | n |
|---:|---:|---:|
| 10 | 100 | 10 |
| 100 | 10,000 | 100 |
| 1000 | 1,000,000 | 1000 |

所以：

```text
n² + n
```

主要影響來自 `n²`。

---

## 3. 保留最高成長項

例如：

```text
O(n² + 3n + 10)
```

簡化成：

```text
O(n²)
```

因為最高成長項是 `n²`。

---

# 八、如何計算時間複雜度？

可以照下面步驟判斷。

---

## 步驟 1：先找 n 是什麼

先問：

> 這段程式處理的資料量是什麼？

例如：

```java
public static void printArray(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        System.out.println(arr[i]);
    }
}
```

這裡的資料量是：

```text
arr.length
```

所以：

```text
n = arr.length
```

---

## 步驟 2：看程式會跑幾次

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

迴圈跑：

```text
n 次
```

所以時間複雜度是：

```text
O(n)
```

---

## 步驟 3：看有沒有巢狀迴圈

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i + "," + j);
    }
}
```

外層跑 `n` 次。

每跑一次外層，內層也跑 `n` 次。

所以總共：

```text
n × n = n²
```

時間複雜度是：

```text
O(n²)
```

---

## 步驟 4：看迴圈是不是每次乘 2 或除 2

### 每次乘 2

```java
for (int i = 1; i < n; i = i * 2) {
    System.out.println(i);
}
```

假設 `n = 16`。

`i` 的變化：

```text
1 → 2 → 4 → 8
```

這不是跑 n 次，而是跑大約：

```text
log₂ n 次
```

所以時間複雜度是：

```text
O(log n)
```

---

### 每次除 2

```java
while (n > 1) {
    n = n / 2;
}
```

假設一開始 `n = 16`：

```text
16 → 8 → 4 → 2 → 1
```

總共除 4 次。

因為：

```text
log₂ 16 = 4
```

所以時間複雜度是：

```text
O(log n)
```

---

## 步驟 5：前後兩段程式，通常用加法

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

for (int j = 0; j < n; j++) {
    System.out.println(j);
}
```

第一段跑 `n` 次。

第二段跑 `n` 次。

總共：

```text
n + n = 2n
```

Big-O 忽略常數 2。

所以：

```text
O(n)
```

---

## 步驟 6：如果有 if / else，看最壞情況

```java
if (condition) {
    for (int i = 0; i < n; i++) {
        System.out.println(i);
    }
} else {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            System.out.println(i + "," + j);
        }
    }
}
```

if 區塊是：

```text
O(n)
```

else 區塊是：

```text
O(n²)
```

通常如果沒有特別說明，就看最壞情況。

所以答案是：

```text
O(n²)
```

---

## 步驟 7：遇到遞迴，看每次問題怎麼變化

### 遞迴例子 1：每次少 1

```java
public static void f(int n) {
    if (n == 0) {
        return;
    }

    f(n - 1);
}
```

假設 `n = 5`：

```text
f(5)
f(4)
f(3)
f(2)
f(1)
f(0)
```

大約呼叫 n 次。

所以時間複雜度是：

```text
O(n)
```

---

### 遞迴例子 2：每次除以 2

```java
public static void f(int n) {
    if (n <= 1) {
        return;
    }

    f(n / 2);
}
```

假設 `n = 16`：

```text
f(16)
f(8)
f(4)
f(2)
f(1)
```

每次砍半。

所以時間複雜度是：

```text
O(log n)
```

---

### 遞迴例子 3：每次分成兩個問題

```java
public static void f(int n) {
    if (n <= 1) {
        return;
    }

    f(n / 2);
    f(n / 2);
}
```

這裡每次呼叫會產生兩個子問題。

大致會變成：

```text
第 0 層：1 個問題
第 1 層：2 個問題
第 2 層：4 個問題
第 3 層：8 個問題
```

這類通常要畫遞迴樹或寫遞迴式分析。

初學者先記：

```text
每次只呼叫自己一次，而且 n 減半 → O(log n)
每次只呼叫自己一次，而且 n 減 1 → O(n)
```

---

# 九、常見時間複雜度由快到慢

| 複雜度 | 名稱 | 直覺 |
|---|---|---|
| O(1) | 常數時間 | 不管資料多大，固定次數 |
| O(log n) | 對數時間 | 每次砍半 |
| O(n) | 線性時間 | 一筆一筆看 |
| O(n log n) | 線性對數 | 常見於高效率排序 |
| O(n²) | 平方時間 | 雙層迴圈 |
| O(n³) | 立方時間 | 三層迴圈 |
| O(2ⁿ) | 指數時間 | 每增加一筆，可能翻倍 |
| O(n!) | 階乘時間 | 排列組合爆炸 |

---

## 用 n = 1000 感覺差異

| 複雜度 | 大約步數 |
|---|---:|
| O(1) | 1 |
| O(log n) | 約 10 |
| O(n) | 1000 |
| O(n log n) | 約 10000 |
| O(n²) | 1,000,000 |
| O(2ⁿ) | 非常巨大 |

# 十、常見判斷口訣

## 1. 沒有迴圈，只做固定操作

```java
int x = arr[0];
```

答案：

```text
O(1)
```

---

## 2. 一層迴圈跑 n 次

```java
for (int i = 0; i < n; i++) {
}
```

答案：

```text
O(n)
```

---

## 3. 兩層巢狀迴圈，各跑 n 次

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
    }
}
```

答案：

```text
O(n²)
```

---

## 4. 三層巢狀迴圈，各跑 n 次

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        for (int k = 0; k < n; k++) {
        }
    }
}
```

答案：

```text
O(n³)
```

---

## 5. 迴圈每次乘 2 或除 2

```java
for (int i = 1; i < n; i *= 2) {
}
```

答案：

```text
O(log n)
```

---

## 6. 前後兩段相加，取最高成長項

```java
for (int i = 0; i < n; i++) {
}

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
    }
}
```

第一段：

```text
O(n)
```

第二段：

```text
O(n²)
```

合起來：

```text
O(n + n²)
```

簡化：

```text
O(n²)
```

# 十一、完整練習

## 練習 1

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

分析：

```text
迴圈從 0 到 n - 1
總共跑 n 次
```

答案：

```text
O(n)
```

---

## 練習 2

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i + "," + j);
    }
}
```

分析：

```text
外層 n 次
內層 n 次
總共 n × n = n² 次
```

答案：

```text
O(n²)
```

---

## 練習 3

```java
for (int i = 1; i < n; i = i * 2) {
    System.out.println(i);
}
```

分析：

```text
i 的變化：
1, 2, 4, 8, 16, 32 ...

每次乘 2
跑的次數約為 log₂ n
```

答案：

```text
O(log n)
```

---

## 練習 4

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

for (int j = 0; j < n; j++) {
    System.out.println(j);
}
```

分析：

```text
第一段 n 次
第二段 n 次
總共 2n 次
Big-O 忽略常數
```

答案：

```text
O(n)
```

---

## 練習 5

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i + "," + j);
    }
}
```

分析：

```text
第一段 O(n)
第二段 O(n²)
合起來 O(n + n²)
保留成長最快的 n²
```

答案：

```text
O(n²)
```

# 十二、考試速記版

```text
O 是 Big-O，大 O 表示法，用來表示成長速度。
n 是資料量。
log n 表示每次縮小問題規模，常見是每次砍半。
O(...) 括弧內放的是操作次數隨 n 成長的型態。
```

國考常見判斷：

```text
固定操作 → O(1)

一層 n 次迴圈 → O(n)

兩層 n 次巢狀迴圈 → O(n²)

三層 n 次巢狀迴圈 → O(n³)

每次砍半 → O(log n)

先後兩段程式 → 相加後取最高成長項

if / else → 通常看最壞情況
```

---

# 十三、最重要觀念總結

時間複雜度可以先想成：

```text
O(括弧裡面的東西)
= 程式步驟數隨資料量 n 增加的成長速度
```

所以：

```text
O(1)       固定時間
O(log n)   每次砍半
O(n)       一筆一筆看
O(n²)      每筆資料又搭配每筆資料看一次
```

最核心的一句話：

> 時間複雜度不是算秒數，而是看資料量變大時，程式執行步驟數成長得多快。

# 十四、產出前確認版

這份筆記的考試用核心結論如下：

```text
1. O 是 Big-O，大 O 表示法。
2. n 是資料量或問題規模。
3. O(...) 括弧內放的是步驟數隨 n 成長的型態。
4. Big-O 初學可理解成成長速度；嚴格來說常用來表示上界。
5. log n 在演算法中常用來表示每次縮小問題規模，例如每次砍半。
6. Big-O 中 log 的底數通常不重要，最後多寫 O(log n)。
7. 固定操作是 O(1)，一層 n 次迴圈是 O(n)，雙層 n 次巢狀迴圈是 O(n²)，每次砍半是 O(log n)。
```

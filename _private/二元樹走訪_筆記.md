# 二元樹走訪 操作筆記

> 從零開始的理解筆記。看不懂時從上往下讀，每段都有例子。
> 全程用這棵樹當例子：
> ```
>         A
>        / \
>       B   C
>      / \   \
>     D   E   F
> ```

---

# 一、最底層觀念（先搞懂這些，後面才看得懂）

## 1. 根（Root）是什麼

**根 = 最上面、上面沒有接任何節點的那一個。**
- 不是因為它叫 A，是因為它在最頂端、沒有上一層。
- 比喻：家族樹裡最老的祖先放最上面，他就是根。
- 上面那棵樹的根是 A。

## 2. 「唸」和「走」是兩個不同動作

| 動作 | 做什麼 | 會留下記錄嗎 |
|---|---|---|
| **唸自己** | 把名字「抄到紙上」(動筆) | ✅ 會。答案就是這樣累積出來的 |
| **走左 / 走右** | 移動腳步去左/右的子節點 (動腳) | ❌ 不會，只是換位置站 |

> 重點：最後的答案那一串字母，全是「唸」累積出來的。「走」只是移動，不產生字。

## 3. 「走左 / 走右」真正的意思

**走左 ≠ 唸一下左邊就結束。**
走左 = **跳到左子節點，把它當成新的根，從頭再跑一次「唸自己→走左→走右」**，做完再回爸爸。

> 例：A 走左到 B，B 不會馬上被唸 —— B 也要遵守規則「先走左」，所以 B 又繼續走到 D。
> 這個規則會一路「傳染」下去，直到某個節點左邊沒路（撞牆）為止。

## 4. 做完要「回爸爸」，從暫停處繼續

每個節點做完自己的三件事，要**退回上一層（爸爸）**，爸爸再從「被打斷的地方」繼續做下一步。
> 像看影片暫停去做別的事，回來是從暫停處繼續播，不是從頭播。

## 5. 樹的本質規則（為什麼要繞）

- **兄弟之間沒有線**：D 和 E 都掛在 B 底下，是兄弟，但**它們之間沒有連線**。
- 所以 **D 不能直接跑去 E**，必須先退回共同的爸爸 B，再由 B 走右到 E。
- 只能沿著線「上下走」(爸爸↔兒子)，不能「左右橫跳」(兄弟之間)。

**這是「樹」這種結構本身的規定**：每個節點只有一個爸爸、路徑唯一、不繞圈。
（若兄弟間也連線、能繞圈 → 就不叫樹，叫「圖 Graph」。）

**二元樹**再多一條限制：每個節點**最多只能有 2 個兒子**（左子、右子），不能有第三個。

## 6. 一律從「根」開始進入

不管哪種走訪，都從**根**這個唯一入口進去。
- 因為其他節點都掛在別人底下，只有根不需要先經過別人就到得了。
- 注意：「從根開始進入」≠「根最先被唸」。誰先被唸要看走訪種類（見下）。

# 二、三種走訪：差別只有一個

每個節點都要做三件事：**唸自己、走左、走右**。
三種走訪唯一的差別 = **「唸自己」插在哪個位置**（走左、走右的先後永遠不變，先左後右）。

| 走訪 | 順序 | 「唸自己」在哪 |
|---|---|---|
| **前**序 Preorder | **唸自己** → 走左 → 走右 → 回爸爸 | 前面 |
| **中**序 Inorder | 走左 → **唸自己** → 走右 → 回爸爸 | 中間 |
| **後**序 Postorder | 走左 → 走右 → **唸自己** → 回爸爸 | 後面 |

> 記法：「前/中/後」這個字，就是在講「自己」站在左右之間的哪個位置。

**關鍵推論**：
- 中序、後序因為「走左」排在「唸自己」前面，所以會**先一路往左鑽到底**，那個最左下角的節點才第一個被唸（這棵樹是 D）。
- 前序因為「唸自己」最先，所以一進去就唸根 A。

# 三、用例子樹實際走三遍

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

## 前序（唸自己→走左→走右）

- 唸 A → 走左到 B → 唸 B → 走左到 D → 唸 D（D 沒小孩，回 B）
- → B 走右到 E → 唸 E（回 B，再回 A）
- → A 走右到 C → 唸 C → 走右到 F → 唸 F

**前序 = A B D E C F**

## 中序（走左→唸自己→走右）

- A 走左到 B，B 走左到 D，D 左邊沒路 → 唸 D
- D 回 B → 唸 B → B 走右到 E → 唸 E
- B 做完回 A → 唸 A → A 走右到 C
- C 走左沒路 → 唸 C → C 走右到 F → 唸 F

**中序 = D B E A C F**
> 注意 B 夾在 D 和 E 中間：因為「從 D 去 E 必須繞回 B」，繞回時剛好唸了 B。

## 後序（走左→走右→唸自己）

- A 走左到 B，B 走左到 D，D 沒小孩 → 唸 D
- 回 B → B 走右到 E → 唸 E
- B 左右做完 → 唸 B
- 回 A → A 走右到 C → C 走左空、走右到 F → 唸 F
- 回 C → 唸 C
- 回 A → 唸 A

**後序 = D E B F C A**

# 四、考試題型：給「前序+中序」，求「後序」

**核心兩條性質**：
1. **前序的第一個 = 根**（因為前序「自己最先」）。
2. **在中序裡，根的左邊全是左子樹、右邊全是右子樹**（因為中序「左→自己→右」）。

**做法**：用前序找根 → 用中序切左右兩半 → 對每一半重複同樣動作。

## 範例（就是本筆記這棵樹）

題目：前序 `A B D E C F`、中序 `D B E A C F`，求後序。

1. 前序第一個 = **A**（根）。
2. 中序用 A 切開：`D B E | A | C F` → 左子樹 = DBE，右子樹 = CF。
3. 拆左子樹 DBE：在前序裡是 `B D E` → 根是 **B**；中序 `D B E` 用 B 切 → 左=D、右=E。
4. 拆右子樹 CF：在前序裡是 `C F` → 根是 **C**；中序 `C F` → C 沒左子、右子=F。
5. 樹重建完成：
   ```
           A
          / \
         B   C
        / \   \
       D   E   F
   ```
6. 寫後序（左→右→自己）：左子樹 DEB + 右子樹 FC + 根 A = **D E B F C A**

**驗算**：拿重建的樹反推前序、中序，對得上題目就對。
- 前序：A,(B,D,E),(C,F) = A B D E C F ✓
- 中序：(D,B,E),A,(C,F) = D B E A C F ✓

# 五、一頁速查

- **根** = 最上面沒爸爸的節點；走訪一律從根進入。
- **唸** = 抄名字到紙上(產生答案)；**走** = 只移動不產生字。
- **走左/走右** = 跳進子節點當新根、重跑規則，做完回爸爸。
- **兄弟沒線**，要繞回共同爸爸；只能上下走不能橫跳。
- **三種走訪只差「唸自己」的位置**：前(前)、中(中)、後(後)。
- 中序/後序會先往左鑽到底，最左下角先被唸。
- **前序首位=根；中序用根切左右**，反覆拆解可重建整棵樹。

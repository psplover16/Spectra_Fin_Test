# CRC 與漢明碼 操作小抄

> 考試/作業時照著步驟做就好。每個步驟後面都附了實際例子。

---

# 一、CRC（循環冗餘檢查）

**用途**：在資料後面加幾位「CRC 碼」，讓對方能檢查資料有沒有傳錯。
（只能發現錯誤，不能修。）

**核心一句話**：把資料湊成「剛好能被除數整除」的數字再傳，對方除得盡就沒錯。

## 操作步驟

**第 0 步：生成多項式 → 翻成二進位**

規則：`X 的次方 = 第幾位是 1`，沒出現的次方補 0。

> 例：G(x) = X³ + X¹
> X³=1, X²=0, X¹=1, X⁰=0 → **1010**（4 位）

**第 1 步：原始資料後面補 0**

補幾個 = 除數位數 − 1。

> 例：除數 1010 是 4 位 → 補 4−1 = 3 個 0
> 原始 1101 → **1101000**

**第 2 步：用 XOR 除法去除**

- 除數對齊「目前最左邊的 1」
- 把除數前後補 0、補到跟被除數一樣長，再整串逐位 XOR
- XOR 規則：一樣=0，不一樣=1
- 對齊位是 0 就跳過、往右移；是 1 才 XOR
- 除數凸出右邊邊界時就停止

> 例：1101000 ÷ 1010
> ```
> 1101000
> 1010000   ← 對齊第1位
> -------
> 0111000
> 0101000   ← 對齊第2位
> -------
> 0010000
> 0010100   ← 對齊第3位
> -------
> 0000100   ← 第4位是0，停
> ```

**第 3 步：取餘數 = 取最右邊幾位（= 補了幾個 0）**

> 例：補了 3 個 0 → 取最後 3 位 = **100**（這就是 CRC 碼）

**第 4 步：原始資料 + CRC 碼 = 要傳的完整資料**

> 例：1101 + 100 = **1101100**

**驗算**：完整資料再除一次除數，餘 0 就對。
> 1101100 ÷ 1010 → 餘 0 ✓

# 二、漢明碼（Hamming Code，偶校驗）

**用途**：加幾個「校驗位」，不只發現錯誤，還能算出錯在第幾位並修好。

**核心一句話**：校驗位放在 2 的次方位置，每個位置的編號決定它歸哪幾組管；哪幾組壞掉，編號一加就是錯誤位置。

**名詞**
- 校驗位 = 額外加的檢查位元
- 偶校驗 = 讓某一組裡「1 的個數」變成偶數（奇數就把校驗位設 1 補成偶數）

## 編碼步驟（發送端：算出要傳什麼）

**第 1 步：算需要幾個校驗位 r**

公式：`2^r ≥ m + r + 1`（m = 資料位數）

> 例：m=4。試 r=3 → 2³=8 ≥ 4+3+1=8 ✓
> 校驗位 3 個，總長度 4+3 = 7 位

**第 2 步：排位置（編號從左到右、從 1 開始）**

- 第 1, 2, 4, 8…（2 的次方）位 → 放校驗位 P1, P2, P4…
- 其餘位置 → 依序填原始資料

> 例：原始 1011
> ```
> 位置: 1   2   3   4   5   6   7
> 內容: P1  P2  1   P4  0   1   1
> ```
> （資料 1-0-1-1 填進位置 3,5,6,7）

**第 3 步：算每個校驗位（偶校驗）**

每組管哪些位置（看位置編號的二進位含不含該值）：
- **P1 管**：1, 3, 5, 7（編號是奇數的）
- **P2 管**：2, 3, 6, 7
- **P4 管**：4, 5, 6, 7

數該組「1 的個數」：偶數 → 校驗位設 0；奇數 → 設 1。

> 例：
> - P1（1,3,5,7）：資料位 3=1,5=0,7=1 → 1有2個(偶) → **P1=0**
> - P2（2,3,6,7）：3=1,6=1,7=1 → 1有3個(奇) → **P2=1**
> - P4（4,5,6,7）：5=0,6=1,7=1 → 1有2個(偶) → **P4=0**

**第 4 步：填回去得答案**

> 例：
> ```
> 位置: 1   2   3   4   5   6   7
> 內容: 0   1   1   0   0   1   1
> ```
> 要傳送：**0110011**

**驗算**：每組 1 的個數都該是偶數。
> P1組:0+1+0+1=2✓　P2組:1+1+1+1=4✓　P4組:0+0+1+1=2✓

## 解碼步驟（接收端：抓錯 + 修正）

**第 1 步：重新檢查每組校驗位**

用收到的資料，數每組「1 的個數」：偶數 → 記 0；奇數 → 記 1。

**第 2 步：拼出錯誤位置編號**

由高位到低位排：`P4 P2 P1`，轉成十進位。
- 結果是 0 → 沒錯
- 結果是 N → 第 N 位出錯

> 例：收到 0110111（第5位被改錯）
> - P1組(1,3,5,7)=0,1,1,1 → 3個(奇) → 1
> - P2組(2,3,6,7)=1,1,1,1 → 4個(偶) → 0
> - P4組(4,5,6,7)=0,1,1,1 → 3個(奇) → 1
> - 拼 P4 P2 P1 = **101** = 5 → 第 5 位錯

**第 3 步：把錯誤那位翻回去（0↔1），就修好了**

> 例：第5位 1 → 翻回 0 → 0110011 ✓

**原理（為什麼編號一加就是錯誤位）**
位置編號的二進位，決定它被哪幾組監督。
> 例：5 = 101 = 4+1 → 只被 P4、P1 管。所以第5位錯時，只有 P4、P1 兩組壞掉 → 拼出 101 = 5。

# 三、兩者快速對照

| | CRC | 漢明碼 |
|---|---|---|
| 能發現錯誤 | ✓ | ✓ |
| 能定位+修正 | ✗ | ✓（單一位元錯誤）|
| 核心運算 | XOR 除法 | 偶校驗分組 |
| 多加的東西放哪 | 全接在資料尾巴 | 插在第 1,2,4,8… 位 |
| 檢查方法 | 重除一次看餘數是否為 0 | 重算各組，編號相加定位 |

試以 SQL 語法,列出各作者之銷售總金額。(3 分)

本 DBMS 是由高速電腦建置的非分散式資料庫系統,執行 SQL 語法查詢時,需先將資料
從硬碟載入記憶體才能運算,為了減少硬碟存取次數,每次載入量為一個硬碟頁。由於存取
硬碟頁的耗用時間,是本 DBMS 進行 SQL 語法查詢的最主要成本,故實際執行查詢前,
估算硬碟頁存取次數將是效能調校關鍵。已知 Product 資料表裡共有 100,000 筆,每一硬
碟頁可存放 200 筆資料,以 pNo 及 unitPrice 為索引所建立的 B+ tree 各有 4 層(含葉節
點),試問以下語法,將分別平均存取幾個硬碟頁? 請列示計算過程。
執行「Select * from Product where pNo='xxxxxx'」(5 分)
執行「Select * from Product where unitPrice>z」(z 為任意整數)(5 分)
答。

#### 擬答

列出各作者之銷售總金額
我們需要從 Buy 表和 Product 表中獲取每個作者的銷售總金額。可以使用以下 SQL 查
詢:
SELECT a.name AS author_name, SUM(b.amount * p.unitPrice)AS total_sales

FROM Author a JOIN Product p ON a.pNo = p.pNo
JOIN Buy b ON p.pNo = b.pNo
GROUP BY a.name;
這個查詢連接 Author 表、Product 表和 Buy 表。計算每位作者的總銷售金額(amount *
unitPrice)。按照作者姓名分組,並返回每位作者的名稱和銷售總金額。
列出達文西的所有「鐵粉」姓名
我們需要查找那些購買了達文西所有書籍的會員。可以使用以下 SQL 查詢:
SELECT m.name
FROM Member m
WHERE m.mId IN (
SELECT b.mId
FROM Buy b JOIN Author a ON b.pNo = a.pNo
WHERE a.name = '達文西'
GROUP BY b.mId
HAVING COUNT(DISTINCT a.pNo)= (SELECT COUNT(*)FROM Author WHERE
name = '達文西'));
這個查詢在子查詢中,找到購買達文西作品的所有會員 ID,並計算他們購買的不同作品
數。檢查每位會員購買的不同作品數是否等於達文西的作品總數。回傳符合條件的會員姓名。
預估硬碟頁存取次數
執行「Select * from Product where pNo='xxxxxx'」
對於查詢 pNo,因為使用了索引,查詢的存取步驟如下:
B+ 樹層數:4 層
索引存取:要從根節點到葉節點,需要 4 個存取次數。
資料存取:一旦找到了葉節點,查詢特定的 pNo 所在的硬碟頁。因為 pNo 是唯一的,只
有一個硬碟頁。
因此,平均存取的硬碟頁數量為:
存取次數=4 (索引)+1 (資料)=5
執行「Select * from Product where unitPrice > z」
對於查詢 unitPrice,這是一個範圍查詢。對於 B+ 樹,範圍查詢的存取步驟如下:
B+ 樹層數:4 層
索引存取:同樣需要 4 個存取次數來到達葉節點。
在查找大於某個值的情況下,可能會在葉節點中需要訪問多個硬碟頁。假設資料分佈是均
勻的,且每個硬碟頁存放 200 筆資料,我們需要考慮的存取次數會是查詢滿足條件的記
錄數量。這個數量無法直接確定,但可以根據資料的分佈進行推估。
假設我們知道 unitPrice 在整體資料中的分佈,假設有 100,000 筆資料,其中 20% 的資
料會符合 unitPrice > z 的條件,則可以預估:
符合條件的數量:100,000×20%=20,000
頁數:⌈20,000/200⌉=100
所以,總的平均存取頁數為:
存取次數=4 (索引)+100 (資料)=104

#### 擬答

使用個案圖(Use Case Diagram)
使用個案圖是由行為者、使用個案與關係組成,標示行為者與使用個案間互動,及使用個案
與使用個案間關係( Relationship)。例如下列之使用個案圖中,就可以描述顧客購物後結

帳系統的動作,此一系統先由經理啟動,接著店員登入後,輸入顧客各單項商品,最後付現
結帳。

```text
使用個案圖範例

店員 ----------------> (輸入單項) <---------------- 顧客
  \                    (登入)                    /
   \-----------------> (付現結帳) <--------------/

經理 ----------------> (啟動系統)
```

| 行為者 | 連結的使用個案 |
|---|---|
| 店員 | 輸入單項、登入、付現結帳 |
| 顧客 | 輸入單項、付現結帳 |
| 經理 | 啟動系統 |

類別圖 (Class Diagram)

```text
+----------------------+
|        person        |
+----------------------+
| -name: String        |
| -address: String     |
| -phone: String       |
+----------------------+
| +purchase()          |
+----------------------+
          ^
          |
+----------------------+
|        student       |
+----------------------+
| -studentID: String   |
+----------------------+
| #getBonus()          |
+----------------------+
```

如上圖,類別被表示成分成三個部分的矩形,最上面是類別名稱,中間部分包含類別的屬性,
底部部分包含類別的操作,類別的屬性(或操作)可以定義有哪些物件能存取(或使用)該
屬性(或操作),這就是類別屬性(或操作)的可視性(Visibility),若一屬性(或操作)允
許所有的類別使用它,便將之可視性設為公開的(public +);若僅允許同一套件內的其他類別
使用,便將之可視性設為套件式(package ~);若僅允許繼承同一類別的其他類別使用,便將
之可視性設為保護的(protected #);若僅允許同一類別使用,便將之可視性設為私有的(private
-)。類別間之關係指的是類別間的連結,在物件導向塑模中,類別間最重要的關係有相依、
一般化、關聯與實現化四種關係。如上圖就是表示student 與person 類別間為一般化關係,
表示student 是一個person。
循序圖(sequence diagram):強調物件之間交互的時間順序,以垂直時間軸來表示物件之間
消息的傳遞順序。循序圖中會繪出許多同時存在的不同物件(以垂直線表示,線的開始及結
束為生命線,表示物件的產生及結束),而物件之間橫向的箭頭,表示物件之間交換的訊息,
會以發生的先後順序來排列。描述系統進行交互作用的行為,實作時就是描述類別間的訊息
交換順序。循序圖以二維圖形來顯示互動情形,縱向是時間軸,以由上而下方式強調物件間
訊息傳遞的時間順序;而橫向則顯示代表動作中個別物件的分類角色,將物件依參與互動的
訊息由左往右擺放,而互動的順序則是由上往下加入。循序圖也有生命線(Lifeline)及控制焦
點(Focus of Control),其中生命線表現出物件互動的時間;控制焦點則表示物件處理某項工
作的所耗費的時間。

溝通圖(Communication diagram):則強調物件之間的關係和消息的傳遞,並不強調時間順
序。溝通圖中,物件之間用連線表示關係,消息用帶有數字標記的箭頭表示。塑模出問題領
域中物件之間互動的情形,重點放在描述一個使用案例執行的過程中,有哪些物件 必須參
與該案例,並且透過合作,傳遞訊息,以完成一個使用案例; 強調合作物件之間的結構,
溝通圖在UML 1.0 時稱為合作圖 (collaboration diagram),用來描述系統如何藉由元件實現
行為。實作時就是描述物件間的結合關係與訊息交換順序。合作圖亦是互動圖的一種,主要

陷可以利用順序編號來解決,只要利用順序編號就可以清楚的知道物件互動順序。

### 五、

#### 題目

五、請實作下列函式以完成設計 1 個插入排序法(Insertion Sort),據以依參數值決定排序方式採遞
增或遞減。(18 分)
bool isInverse(int x, int y, bool isAsc); //判斷傳入的 x、y 是否反序
void InsertionSort(int *arr, int len, bool isAsc); //插入排序
(註:參數 arr 為傳入的整數陣列;參數 len 為整數陣列的長度;參數 isAsc 為是否遞增,
函式 InsertionSort 應呼叫函式 isInverse。)

#### 擬答

以下是使用 C 語言實作的插入排序法(Insertion Sort),包括 isInverse 和 InsertionSort 函式。
isInverse 函式用來判斷兩個數是否反序,而 InsertionSort 則根據 isAsc 參數決定排序方式是
遞增還是遞減。
#include <stdbool.h>
// 判斷傳入的 x、y 是否反序
bool isInverse(int x, int y, bool isAsc){
if (isAsc){
return x > y; // 如果是遞增排序,當 x > y 時返回 true
} else {
return x < y; // 如果是遞減排序,當 x < y 時返回 true
}
}
// 插入排序
void InsertionSort(int *arr, int len, bool isAsc){
for (int i = 1; i < len; i++){
int key = arr[i];

int j = i - 1;

// 根據 isInverse 函數的結果,決定是否要將元素向後移動
while (j >= 0 && isInverse(arr[j], key, isAsc)){
arr[j + 1] = arr[j];
j--;
}
arr[j + 1] = key; // 將 key 放到適當的位置
}
}
// 測試函式
#include <stdio.h>
void printArray(int *arr, int len){
for (int i = 0; i < len; i++){
printf("%d ", arr[i]);
}
printf("\n");
}
int main(){
int arr[] = {5, 2, 9, 1, 5, 6};
int len = sizeof(arr)/ sizeof(arr[0]);
printf("Original array: ");
printArray(arr, len);
// 遞增排序
InsertionSort(arr, len, true);
printf("Sorted array (ascending): ");
printArray(arr, len);
// 再次排序為遞減
InsertionSort(arr, len, false);
printf("Sorted array (descending): ");
printArray(arr, len);

return 0;
}
解題說明
isInverse 函式:
判斷 x 和 y 是否反序,根據 isAsc 的值來決定:
若 isAsc 為 true,則判斷 x > y,這表示在遞增排序時,若前一個數大於後一個數,則需
要交換,返回 true。
若 isAsc 為 false,則判斷 x < y,這表示在遞減排序時,若前一個數小於後一個數,則
需要交換,返回 true。

InsertionSort 函式:
使用插入排序的基本邏輯,從索引 1 開始迭代陣列。
將當前元素(key)與已排序的部分進行比較,透過 isInverse 函數決定是否需要移動元
素。
如果 isInverse 返回 true,則表示元素位置不正確,需要將元素向後移動,直到找到正確
的位置插入。
測試部分:對陣列進行遞增排序和遞減排序的測試,並印出結果以驗證程式的正確性。

### 六、

#### 題目

六、請使用程式語言設計 1 個低時間複雜度的函式,傳入 a、b 皆為不大於 2^30 的正整數後,可
判斷出 |a - b| 的值是否只有 3 個因數,並註明所使用的程式語言。(20 分)
(註:該函式只允許呼叫平方根函式。)

#### 擬答

以下是使用 Python 實現的低時間複雜度函式,該函式可以判斷兩個不大於 2^30 的正整數 a
和b 的絕對差值是否只有 3 個因數。這個函式只會呼叫平方根函式來進行因數判斷。
import math
def has_three_factors(a, b):
# 計算 |a - b| 的絕對值
diff = abs(a - b)
# 如果差值為 1 或小於 1,則不可能只有三個因數
if diff <= 1:
return False
# 計算 diff 的平方根
sqrt_diff = int(math.isqrt(diff))
# 如果平方根的平方等於 diff,且 sqrt_diff 是質數,則 diff 只有 3 個因數
# 因數為 1、sqrt_diff、和 diff 本身
if sqrt_diff * sqrt_diff == diff:
# 判斷 sqrt_diff 是否為質數
for i in range(2, int(math.sqrt(sqrt_diff))+ 1):
if sqrt_diff % i == 0:
return False
return True
return False
# 測試範例
print(has_three_factors(18, 9)) # True, |18-9|=9 有 1, 3, 9 三個因數
print(has_three_factors(20, 8)) # False, |20-8|=12 有超過三個因數
print(has_three_factors(17, 1)) # False, |17-1|=16 有 1, 2, 4, 8, 16 五個因數
解題說明
計算∣a−b∣ 的絕對值 diff。

如果 diff 的平方根是整數,且平方根是質數,那麼 diff 就只有三個因數:1、平方根、以及 diff

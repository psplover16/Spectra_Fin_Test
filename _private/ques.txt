3. 計概
3a. 基本計概
馮紐曼架構：2 大特色、5 大單元；馮紐曼瓶頸是什麼；怎麼解決。
圖靈機：定義；有哪三個單元；圖靈測試。

機器指令：定義；機器指令週期有哪 5 個（印象中選擇題常出）。

Pipeline：定義；管線化的計算題要會。

匯流排：位址、資料和控制匯流排的定義；n bits 位址匯流排產生多少個記憶體空間；n bits 資料匯流排一次可傳送多少位元的資料；三種匯流排的傳輸方向；

MIPS、CPI、內外頻、Clock、Clock Cycle、Clock Rate 的定義；Clock Cycle 和 Clock Rate 相關的計算題

RISC、CISC：定義；兩個之間的差異（指令數、定址模式、編譯器翻譯出的指令數、誰需要強力 compiler、暫存器數量、指令長度、誰適合 Pipeline、代表架構和指令週期誰比較長等）。

memory 階層圖：圖要記，會出在選擇。用階層圖來比較速度、成本和空間；cache、main memory 分別屬於 SRAM 還是 DRAM；記憶題的時間、空間 locality。

memory 分類圖：圖要記（這個和階層圖不同）；ROM、RAM 的比較表；DRAM、SRAM 的比較表；PROM、EPROM 和 EEPROM 的比較表。

Register：Program Counter、Instruction Register、Base Register、Limit Register 和 Flag Register 的用途。

Cache：L1、L2 Cache；什麼是 Hit Ratio；Write Through 和 Write Back 是什麼？

Hazard：定義；Structural、Data 和 Control Hazard 的發生原因；解決方式？

USB：USB 1.0～4.0 的速度。

進制轉換：10 轉 n、n 轉 10 進制；2 的冪次方的進制轉換。

補數轉換：計算符號大小、1’s、2’s 補數轉換；記一下它們的表示範圍。

浮點數轉換：傳統表示法和 IEEE 754 表示法要會算，千萬不要去背它們的轉換規則，題目算多了有肌肉記憶，下次遇到類似題目就會算。

數碼、文字碼和檢查碼：BCD、2 進制轉格雷碼、格雷轉 2 進制、ASCII、EBCDIC、Unicode 都蠻基本的，一定要會。接下來是比較常考的，同位元檢查、CRC、漢明碼和漢明碼距一定要會算，會出在選擇題。

3b. 數位邏輯
邏輯閘、求布林函式的 SOP 和 POS、卡諾圖化簡、怎麼用 2 種萬用閘實現其他邏輯閘的功能（用幾個萬用閘可以看一下）。至於半加器、全加器、正反器、編/解碼器和多工/解多工器，國營聯招似乎比較少考，我這次就全跳過。

3c. 作業系統
基本常識：整理 OS 的分類比較表（定義、優缺點和實例）；Concurrency、Parallelism 的定義、實際例子，用廚師煮菜的例子去理解；Offline、Spooling、Buffering、Cache 的定義、為何採用這些設計？

I/O 的中斷方式：理解 Polling、Interrupt 和 DMA 的中斷流程，建議畫圖。三種中斷（NMI、Interrupt（內/外部）、Trap）的定義和實例。

硬體保護：I/O、Memory 和 CPU Protection 的運作流程。

OS 的結構：稍微看一下 Command、System call 各自的定義、負責的功能；比較 Kernel 和 Microkernel 的定義和功能；Virtual Machine 的定義和優缺點。

Process：Process 的定義、包含哪些部分？Process vs Program；Process State Transition Diagram；Process Control Block；Long、Short 和 Medium Term Scheduler；Context Switch；Preemptive vs Non Preemptive；Starvation；Convoy Effect；各種 CPU Scheduling Algorithm 的定義、優缺點，相關的計算題一定要會。

Deadlock：定義、4 個必要條件；Deadlock Prevention、Deadlock Avoidance、 Deadlock Detection & Recovery 還有相關的計算題一定要會。

Process Communication：這章我跳過。

Memory Management：First/Next/Best/Worst Fit；External/Internal Fragmentation；Page/Segment Memory Management；TLB（Transaction Lookaside Buffer）

Virtual Memory：定義；Demand Paging；Page Fault（定義、影響 Page Fault Ratio 的因素）；Effective Memory Access Time 的計算；Page Replacement Algorithm（定義、優缺點、計算題必考）；Thrashing（定義、造成 Thrashing 的過程圖、解法）

Disk Management：Continous、Link、Index Allocation 和 FAT 的定義和優缺點；Disk 的結構、計算存取時間；RAID 的比較；Disk Scheduling Algorithm 的比較；

4. 資料結構 & 演算法
這堂課有許多專有名詞需要記憶（像是和 Tree 有關的名詞），唯一不能記的就是程式碼！ 甚至連虛擬碼都不要記！因為考題是會變化的，與其浪費時間記憶程式碼，不如把時間花在理解程式在做什麼事。如果覺得有些觀念很抽象的話，建議畫圖理解，之後遇到類似的觀念，腦海中會浮現畫面，理解速度會加快！

首先，一定要記時間複雜度的比較圖，幾乎是必考！

章節中比較困難的是「圖」和「排序」！在理解圖形相關的演算法時，先看圖和程式碼（或是虛擬碼）照著流程跑一次，大概想一下為什麼要這樣跑？為什麼會有這個結果？接著，試著把程式碼整理成虛擬碼，再把虛擬碼寫成程式碼。上面的步驟都沒問題代表理解的差不多了！

排序的話，剛開始理解的時候，把每個步驟每個元素在什麼位置都畫出來就很好理解了！然後再照我上面說的方法加深印象。

「高等樹」這個章節要搞懂是怎麼排序的，還有要會寫虛擬碼，印象中歷年來沒有考過高等樹的程式碼。以下附上我的筆記的知識點：

演算法：定義；5 個滿足條件

時間複雜度：O(n) 表示法和計算題；Big O 表示法的比較圖

陣列：特色；一、二維陣列的位址計算題；

Link List：特色；運作原理；和 array 的比較表；插入/刪除（在 head 前、在 tail 後和在節點中間）；單向、環狀和雙向 Link List；相關的虛擬碼都要會寫

Stack、Queue：特色；運作原理；實際應用；Stack、Queue、Array 和 Link List 的比較表；虛擬碼；Circular Queue

Tree：定義；基本術語；Binary Tree 的定義、特性和 Binary Tree vs Tree、前中後序轉換

圖：定義；基本術語；DFS vs BFS、Spanning Tree、Kruskal’s、Prim’s Algorithm；Dijkstra’s、Floyd-Warshall Algorithm、AOV、AOE 網路

排序：定義；7 種常見排序法的比較（時間複雜度（平均、最好、最差）、穩定性、程式碼、虛擬碼）

高等樹：AVL Tree（定義、特性、插入、刪除、時間複雜度）；B Tree（定義、特性、搜尋、插入、刪除、時間複雜度）；Heap Tree（定義、特性、插入、刪除、搜尋、時間複雜度）；紅黑樹（定義、特性、插入、刪除、時間複雜度）

雜湊法：定義、Overflow 的處理方式
